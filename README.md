# آکادمی زبان استاد مهدوی — نسخه آماده GitHub Pages

این پروژه یک وب‌سایت استاتیک است: برای انتشار آن نیازی به نصب Node.js، اجرای دستور build یا تنظیمات پیچیده نیست.

## انتشار روی GitHub Pages

1. در GitHub یک مخزن جدید بساز؛ مثلاً `mahdavi-academy`.
2. فایل‌ها و پوشه‌های همین بسته را در ریشه مخزن بارگذاری کن. ساختار باید این‌طور باشد:

   ```text
   index.html
   README.md
   assets/
     favicon.svg
     ostad-mahdavi.jpg
   ```

3. در مخزن وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/(root)` را انتخاب و **Save** کن.
6. بعد از تکمیل انتشار، نشانی سایت در همان قسمت Pages نمایش داده می‌شود. معمولاً ساختار آن `https://USERNAME.github.io/REPOSITORY/` است.

## نکات مهم پیش از انتشار عمومی

- دوره‌ها، قیمت‌ها و تعداد درس‌ها در این نسخه نمایشی‌اند؛ اطلاعات واقعی را جایگزین کن.
- تصویر استاد از تصویری استفاده می‌کند که برای پروژه فرستاده شده بود.
- تصاویر برخی کارت‌های دوره از Unsplash بارگیری می‌شوند؛ برای اجرای آفلاین می‌توانی آن‌ها را دانلود کرده و در پوشه `assets` قرار دهی.
- این نسخه فقط فرانت‌اند است. فرم ثبت‌نام نمایشی است و هیچ داده‌ای ارسال یا ذخیره نمی‌کند. ورود واقعی، پنل مدیریت امن، پایگاه داده، سفارش و پرداخت ویدئو به بک‌اند نیاز دارند؛ GitHub Pages به‌تنهایی این موارد را فراهم نمی‌کند.
- پیش از انتشار تجاری، اطلاعات تماس واقعی و جزئیات نهایی دوره‌ها را اضافه کن.
